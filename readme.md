## 🚀 Key Features & Architectural Highlights

- **💻 Interactive DevOps Terminal Sandbox (`jaydeep@london-eks:~#`)**:
  - Live interactive CLI in the Hero section supporting real commands (`status`, `arch`, `skills`, `benchmarks`, `experience`, `resume`, `contact`, `clear`) and quick-action chips.
- **🌐 Interactive Cloud Architecture Topology Visualizer**:
  - 5-stage distributed architecture schematic (Edge Ingress $\leftrightarrow$ AWS EKS Compute $\leftrightarrow$ Low-Latency Risk Engine $\leftrightarrow$ In-Memory Redis Cache $\leftrightarrow$ Multi-Region Aurora & OCI Vault) with live node telemetry updates on hover.
- **🃏 3D Perspective Tilt Bento Cards**:
  - Hardware-accelerated 3D mouse perspective physics for featured projects, including the live **NetWealth** multi-broker platform ([netwealth.tech](https://netwealth.tech)), **Atlas Transformation**, **RiskOne**, and **dbPalace**.
- **🛸 Floating Cockpit Dock & Keyboard Shortcuts Engine**:
  - Minimal floating navigation dock with keyboard hotkeys (`1-5` for sections, `T` for Terminal focus, `R` for Resume PDF, `⌘K` for Spotlight Search).
- **💼 Executive Career Flight Deck**:
  - Interactive dossier switcher showcasing tenure across JPM Personal Investing, JPMorgan Services India, Deutsche Bank Group, and early career.
- **⭐ LinkedIn Verified Peer Reviews**:
  - Direct peer testimonials from engineering leaders at Goldman Sachs, Harness, and Microsoft.
- **🔄 Cross-Repository CI/CD Pipeline**:
  - Official PDF resume automatically compiled via [Tectonic](https://tectonic-typesetting.github.io/) in the private [`resume-as-code`](https://github.com/jaydeepmohite/resume-as-code) repository and deployed directly to this repository on merge to `main`.
- **🔍 100% SEO & Core Web Vitals Optimized**:
  - Complete Schema.org JSON-LD Person & ProfilePage metadata, OpenGraph & Twitter Cards, `robots.txt`, and XML `sitemap.xml`.
