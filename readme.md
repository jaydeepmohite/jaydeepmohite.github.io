## 🚀 Key Features & Architectural Highlights

- **🎛️ Interactive Executive Workspace (Tabbed Navigation)**:
  - Eliminates long vertical scrolling through an app-like tabbed dashboard featuring **Overview**, **Projects**, **Experience**, **Skills**, and **Endorsements & Contact**.
  - Supports deep linking and URL hash routing (`#overview`, `#work`, `#experience`, `#skills`, `#credentials`).
- **💼 Interactive Company Experience Selector**:
  - Instant view switcher for career history spanning JPM Personal Investing (London, UK), JPMorgan Services India (Bengaluru), Deutsche Bank Group (Pune), and early career internships.
- **📱 100% Screen-Size Friendly & Fluid Mobile Layout**:
  - Responsive tabbed navigation dock that automatically converts into a mobile pill switcher.
- **⚡ Vanilla Engineering & Zero Legacy Dependencies**:
  - Built with pure HTML5, vanilla CSS3 design system, and lightweight ES6+ JavaScript (zero jQuery or bloated libraries).
- **🌓 Dark & Light Mode Theme Switcher**:
  - Persistent theme switching with system preference auto-detection.
- **📋 1-Click Clipboard Helpers & Live London Clock**:
  - Fast email & mobile copying with animated toast feedback and live London GMT/BST clock.
- **🔍 100% SEO & Core Web Vitals Optimized**:
  - Schema.org JSON-LD structured data (`Person` & `ProfilePage`), OpenGraph and Twitter social cards, `robots.txt`, and XML `sitemap.xml`.
